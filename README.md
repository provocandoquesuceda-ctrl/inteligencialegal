# Asistente Legal IA (Privado y Local)

Una interfaz web ligera, segura y 100% privada diseñada para que profesionales del derecho puedan realizar consultas, redactar contratos y analizar casos de forma local, garantizando que el secreto profesional no se vea vulnerado por servidores externos.

## 🚀 Requisitos Previos

1. **Ollama instalado:** Descárgalo e instálalo desde [ollama.com](https://ollama.com).
2. **Modelo descargado:** Abre tu terminal y ejecuta el siguiente comando para descargar el modelo por defecto:
   ```bash
   ollama run llama3.2
   ```
3. **Servidor activo:** Asegúrate de que Ollama se esté ejecutando en segundo plano (escuchando de forma nativa en `http://localhost:11434`).

## 🛠️ Instalación y Uso

1. Descarga o clona este repositorio en una carpeta local de tu computadora.
2. Abre el archivo `index.html` directamente en cualquier navegador moderno (Chrome, Edge, Firefox, Brave).
3. El sistema comprobará automáticamente la conexión local. Cuando el indicador de estado se ponga en verde, podrás escribir tus consultas jurídicas.

## 🔒 Privacidad Garantizada

A diferencia de soluciones comerciales en la nube:
* Los datos **nunca salen de tu máquina**.
* Cumple estrictamente con regulaciones de protección de datos (como el secreto profesional y normativas locales de privacidad).
* Funciona completamente **sin conexión a Internet**.
